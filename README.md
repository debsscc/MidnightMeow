# MidnightMeow

Jogo criado na GameJam+ 25/26 — survivor 2D (gato vs ratos) com suporte multiplayer.

## Unity

- Versão: **6000.3.13f1**
- Abrir a pasta do projeto no Unity Hub

## Documentação

Toda a base de conhecimento para o time e agentes de IA está em **[docs/README.md](docs/README.md)**.

## Manutenção

1. Leia as práticas em `docs/practices/`
2. Atualize `docs/editor/` ao mudar prefabs ou cenas
3. Mova assets sempre com o arquivo `.meta`
4. Rode o Test Runner após mudanças em lógica (`Assets/Tests/`)
